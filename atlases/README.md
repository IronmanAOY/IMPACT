# Brain atlases

The parcellations that fMRI preprocessing reads: Schaefer-400 (7 networks),
AAL-116 (AAL for SPM12) and Shen-268. They are third-party data; sources,
licenses and SHA-256 values are in `licenses/THIRD_PARTY_NOTICES.md`.
Check the local copies with `bash scripts/download_atlases.sh --verify` and
re-fetch missing files with `bash scripts/download_atlases.sh`.
